# 虚构样例

**全部虚构数字，结构与真实业务一致，真实数据永不入库。**

两份 xlsx 为设计文档附录A的虚构配置A/B（与 `tests/conftest.py` 测试夹具逐字一致），
算法模式=成本加成（markup），统一利润率=0.10，有效期至 2026-12-31。
派生列按附录B口径由程序计算（B.7 期望值总表）：

| 文件 | 整机底价 | 整机报价 | 利润额(不含税) | 加成率 | 毛利率 |
|---|---:|---:|---:|---:|---:|
| 虚构配置A.xlsx（全部专票） | 5800.00 | 6380.00 | 513.27 | 10.00% | 9.09% |
| 虚构配置B.xlsx（CPU 普票，其余专票） | 4130.00 | 4543.00 | 365.49 | 10.00% | 9.09% |

## 重新生成

仓库根目录运行：

```bash
.venv/Scripts/python.exe samples/make_samples.py
```

重复运行会先清理旧样例与 `.bak`，生成结果恒为 v1（创建人/修改人=虚构操作员，日志 1 条）。

## 文件结构

四张表：报价总览 / 部件明细 / 审批记录 / 修改日志；表头第 1 行、数据第 2 行起。
派生列（整机底价/整机报价/利润额/加成率/毛利率、件底价/件报价）由程序计算，
用程序打开即重算；用 Excel 手改成本后再用程序打开，会重算派生列并警告「文件曾在程序外被修改」。
保存为原子写入（.tmp → 旧版转 .bak → 替换），版本号每次保存 +1，修改日志只增不改。
`.bak` 备份已被 .gitignore 排除，不入库。

## 数据边界（红线1）

真实报价文件（`data/`、`exports/`、`*_客户_*.xlsx`、`*_审批_*.xlsx`）均被 .gitignore 排除，
永不入库；本目录只放附录A虚构样例。
