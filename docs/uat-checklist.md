# GUI 用户验收清单（UAT）— pc-quote-flow v0.1.0

> 依据：设计文档 v5 附录A/B（期望值唯一权威）、实现计划 Task 10 Step 5。
> **全部数字为附录A虚构样例**。真实报价数据永不入库（红线1）：真实文件只放
> `data/`、`exports/`（均已 .gitignore 排除）。
> 程序**不做审批决策、不强制拦截、不做权限控制**（红线2）：低于底价仅红色警告 +
> 导出前一次确认 + 日志留痕，任何按钮都不会被禁用。

## 准备

- [ ] 打包产物就绪：`dist/pc-quote-flow.exe`（单文件、双击即用，无控制台窗口）。
- [ ] 可选预检（命令行）：`dist\pc-quote-flow.exe --selftest` 后 `echo %errorlevel%`
      应为 **0**，且 `%TEMP%\pc-quote-flow-selftest.log` 末行为 **SELFTEST OK**。
- [ ] 把样例**复制**到 `data/` 再验收（避免改动仓库内样例）：
      `samples/虚构配置B.xlsx` → `data/虚构配置B.xlsx`（`data/` 不存在则新建）。
- [ ] 导出文件建议保存到 `data/` 或 `exports/`（均已 .gitignore 排除）。

## ⓪ 人工数学核算（用户/财务）

- [ ] 打开 `docs/math-verification-report.md`，对照设计文档附录 **B.7 期望值总表**
      逐行核算：12 用例、48 项比对，程序输出 = 独立 Decimal 重算 = 表期望值。
- [ ] 手算抽查（B.7 人工核算步骤③）：一件普票 **1000×1.13=1130**；
      一笔利润 **(4543−4130)/1.13=365.49**。
- [ ] （可选）本机另用真实配置文件复核程序四数；**真实数字与文件不入仓库**。

## ① 首次运行登记

- [ ] 双击 `dist/pc-quote-flow.exe`：首次运行弹出登记框——姓名（预填 Windows
      用户名，可改成真实姓名）+ 角色（采购｜销售客服｜管理层，默认"销售客服"）。
- [ ] 填写并确认后进入主窗口，工具栏"当前操作人"标签显示 姓名+角色；
      身份存于 `%APPDATA%\pc-quote-flow\profile.json`（不进报价文件）。

## ② 打开样例核对四数（B.7 行5）

- [ ] 打开 `data/虚构配置B.xlsx`（模式"成本加成"、统一利润率 10）。
- [ ] 四数面板：**客户报价 4543.00 ／ 利润(不含税) 365.49 ／ 加成率 10.00% ／
      毛利率 9.09%**；整机底价 **4130.00**（B.7 行4）。

## ③ 低于底价：红色警告 + 导出一次确认（不拦截）

- [ ] 统一利润率改为 **−5**：出现**红色**低于底价警告；三个导出按钮**仍可点击**。
- [ ] 点"导出客户报价单"→ 选保存位置 → 弹出"低于底价确认"对话框（仅一次）→
      确认后**导出成功**（状态栏提示已导出）。
- [ ] 测试完毕把统一利润率改回 **10**，四数恢复②的数值（后续步骤均以加成 10% 为基准）。

## ④ 客户报价单脱敏（红线5）

- [ ] 用 Excel/WPS 打开③导出的客户报价单：确认**无成本、无供应商、无商品链接**，
      亦无确认价/实际价/订单号；检查**隐藏列、批注、文档属性**也不携带内部数据。

## ⑤ 审批文件 + 审阅视图（仅记录，不门禁）

- [ ] 点"导出审批文件"→ 导出成功（审批文件含全部内部数据与合理性摘要）。
- [ ] 切到**审阅视图**：全列只读；审批摘要块显示底价/报价/利润/两率/是否低于底价等。
- [ ] 点"填写审批意见"→ 结论选"**同意**"+ 填意见 → 确认后状态变为"**采购中**"，
      审批记录 +1，修改日志含"审批记录"条目。

## ⑥ 采购视图：链接 / 确认价 / 实际价回写

- [ ] 先在销售视图给 CPU 行"商品链接"填测试链接（如 `https://example.com/item`），
      切到采购视图**双击链接单元格** → 浏览器打开该链接。
- [ ] 给 CPU 填**确认价 2000**（确认发票类型：普票）→ **立即**出现红字
      "**已低于底价，请按公司流程审批**"（纯 GUI 录入即生效，无需重新保存/打开）；
      确认后底价显示 **5260.00**（=4130−1130+2000×1.13，计划 Task 9 期望值）；
      导出按钮仍可用。
- [ ] 回写 CPU **实际成交价 1050**（实际发票类型：普票）→ 真实利润 **315.49**，
      出现**侵蚀提示**（相对报价时预期利润 365.49）；不阻止任何操作。

## ⑦ 修改日志盖章（红线4）

- [ ] 审阅视图"修改日志"表：上述每步写操作各有一条盖章——
      **时间 / 操作人(姓名+角色) / 机器名 / Windows账户 / 当前视图 / 动作 /
      字段变更摘要 / 文件版本**；日志**只增不改**（历史条目不被改写）。

## ⑧ 保存留 .bak

- [ ] 再次保存工作文件 → 同目录出现同名 **`虚构配置B.bak`**，文件版本号 +1。

## ⑨ 反算写回合计精确（B.7 行8）

- [ ] 销售视图点"反算写回…"→ 目标整机报价输入 **4555.55** → 预览反算加成率
      ≈**10.30%** → 点"写回"。
- [ ] 写回后整机报价合计**精确 4555.55**；CPU 件报价 **1246.44**（尾差仅由底价
      最大件吸收）；单项利润率被清空；日志摘要含"反算写回/尾差"。
