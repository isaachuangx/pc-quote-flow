## 1. 验证方法

- **独立侧**：按附录B公式用 Decimal 从头重算（ROUND_HALF_UP 舍入到分、中间量全精度），
  **不导入程序的 pricing/tax/money 计算函数**；pricing 仅作为被测程序调用，model 为纯数据类。
- **逐项比对**：程序输出 vs 独立重算 vs 附录B.7 期望值总表（给出表期望时三者须一致）。
- 行1/4 的不含税成本 C 与应缴增值税按 B.2 恒等式从程序底价导出比对：
  C = B/(1+t)；应缴增值税 = B − 采购合计（B = S+P+P×t）。
- 关键口径（附录B.1–B.5）：件底价贡献 专票=p×n、普票=p×n×(1+t)（全精度）；
  件报价 加成=round(f×(1+r))、毛利率=round(f÷(1−m))；整机报价 Q=Σ舍入后件报价；
  利润(不含税)=round((Q−B)/(1+t))；反解 r*=(T−B)/B、m*=(T−B)/T（全精度），
  写回尾差 δ=T−Σq 仅由底价最大件吸收；采购回写有效价回退链 实际→确认→报价时。
